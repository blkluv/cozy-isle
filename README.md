# 悠然小岛 Cozy Isle 🏝️

一款动森风（Animal Crossing-style）的治愈系小岛网页游戏——在低多边形小岛上
散步、和村民聊天、摇果树、钓鱼，完成今日任务后回广场参加篝火庆祝。

灵感来自 X 上分享的一段游戏视频。代码、模型、名称与视觉全部为**原创重实现**——
所有资产都是用 [Three.js](https://threejs.org) 手写的程序化低多边形几何体，
未使用原作的任何素材。

## 运行

```bash
npm install
npm run dev      # → http://localhost:5173
```

```bash
npm run build    # 类型检查 + 生产构建到 dist/
```

## 怎么玩

| 操作 | 效果 |
|---|---|
| `W A S D` / 方向键 | 走路 |
| 鼠标拖拽 / 滚轮 | 旋转视角 / 缩放 |
| `E` | 聊天 · 摇树 · 抛竿 / 收竿 |
| `F` | 吃苹果（体力 +30） |
| 触屏 | 左半屏虚拟摇杆 + `E` 按钮 |

**今日任务**：钓一条鱼 🎣、摇树捡掉落物 🌳、和村民聊天 💬——
全部完成后回中央广场参加庆祝 🎉（篝火会在庆典时点亮）。

钓鱼：在水边抛竿，看到 **❗ 有鱼咬钩！按 E** 立刻收竿。
共有 5 种渔获（包括一只泡水的旧靴子 🥾）。

## 技术栈

- Vite + TypeScript + Three.js（无引擎、无素材文件、无后端）
- 程序化低多边形世界：小岛、河流与木拱桥、圆顶小屋、灯塔、果园、棕榈、松树、篝火广场
- 几何体拼装的 Q 版动物角色，走路/待机动画纯代码驱动
- WebAudio 合成的音效（无音频文件）、DOM/CSS 实现的 HUD 与彩带

## 实现原理

整个游戏零素材：没有一个模型文件、贴图或音频，全部由代码生成。

### 模块划分

```
src/
├── main.ts       入口：创建 Game，启动渲染循环
├── game.ts       游戏主类：状态、任务、钓鱼、掉落物、HUD、输入、相机
├── world.ts      世界生成：地形/建筑/植被 + 碰撞与行走判定
├── character.ts  Q 版动物角色拼装 + 程序化走路/待机动画
├── villagers.ts  4 个村民的定义（名字/配色/台词）与漫游 AI
├── audio.ts      WebAudio 振荡器合成音效（无音频文件）
└── style.css     HUD 样式（圆角治愈风）
```

### 世界生成（world.ts）

- **地形**：两个叠放的圆柱体构成小岛（上层草地、下层沙滩裙边），外面两片大圆盘是海洋；
  河流是嵌在地表的蓝色长条 + 沙岸，不做布尔运算，视觉上读取为溪流。
- **建筑**：桥由 14 块沿正弦弧线排布的木板 + 分段弯曲的栏杆拼成；小屋是圆柱墙 +
  半球屋顶；灯塔是四段红白相间的圆柱。全部 `MeshStandardMaterial({ flatShading: true })`
  得到低多边形硬边质感。
- **植被**：苹果树 = 锥形树干 + 3 个球体树冠 + 6 颗小红球；棕榈 = 5 节渐弯树干 +
  6 片压扁拉长的圆锥叶；装饰（草簇/郁金香/蘑菇/芦苇/石头）用 `mulberry32` 种子随机布点，
  保证每次加载布局一致。
- **碰撞**：全部简化为数据而非物理——圆形障碍列表（树干/灯/家具/房屋）+ 河流矩形带
  （桥内豁免）+ 岛缘半径限制。`isWalkable(x,z)` 一个纯函数回答"能不能站"，
  移动时用 x/z 分轴尝试实现贴墙滑动。`groundY(x,z)` 在桥面上按正弦拱起，
  所以走过桥会自然爬坡。
- **环境生命**：云漂移、鸟盘旋扑翅、蝴蝶绕花、篝火未点燃（庆典才点亮）、
  可摇树下的黄色提示圈呼吸脉动——全部挂在 world.tick 里按时间驱动。

### 角色（character.ts）

- Q 版比例 = 大头（0.46 球）+ 小身体（0.42 球）+ 胶囊四肢；狗/鹿/羊/熊的差异
  只在头部配件（垂耳/鹿角/羊毛球/圆耳）和配色。
- 动画不写关键帧：步行时 `sin(walkT)` 驱动四肢反相摆动、身体上下 bob；
  待机时切换成低频呼吸 + 头部缓慢扫视。朝向用指数阻尼（dampAngle）平滑转身。

### 玩法系统（game.ts）

- **任务**：数组 + 完成态；任一任务完成 → Toast + 音效 + 划线勾选；全部完成 →
  900ms 后追加「回广场庆祝」任务；进入广场半径 → 点燃篝火、DOM 彩带、村民围拢。
- **钓鱼**：状态机 `casting → waiting → bite → caught`。抛竿是 0.55s 的抛物线插值；
  等待期水下有鱼影游向浮漂；咬钩 1.15s 窗口内按 E 才成功，超时鱼跑。
  渔获按权重表抽取（鲈鱼/鲤鱼/锦鲤/金鱼/旧靴子）。
- **摇树**：树冠按阻尼振荡摇摆，掉落物走"抛物线 → 地面弹跳 → 磁吸飞向玩家"三段式，
  吸收瞬间结算奖励；树有 24s 冷却（黄圈隐藏，苹果重新长出）。
- **经济**：任务 +25、苹果 +6、渔获 +1~40、庆典 +50；体力随行走缓慢消耗，吃苹果回复。

### 相机与输入

第三人称轨道相机：`yaw/pitch/dist` 三参数，鼠标拖拽改 yaw/pitch、滚轮改 dist，
位置用 `MathUtils.damp` 平滑跟随；移动输入按相机 yaw 旋转换算成世界方向，
所以按键方向永远符合直觉。触屏设备自动启用左半屏虚拟摇杆 + E 按钮。

### HUD 与音效

HUD 是盖在 canvas 上的 DOM 层（Baloo 2 + 系统中文字体栈），Toast 用
`column-reverse` 从下往上叠；彩带是 90 个随机色 DOM 小块自由落体。
音效全部运行时合成：两个振荡器做任务完成琶音、带通噪声做水花/树叶沙沙、
正弦滑音做抛竿——首次输入时才创建 AudioContext 以满足浏览器自动播放策略。

### 部署

`npm run build` 产出纯静态 `dist/`（含 tsc 类型检查），通过
Cloudflare Workers Static Assets 发布到 `workers.dev`。
